# Rooster One — Frontend

Frontend do Rooster One — TanStack Start + React + Tailwind.

Documentação completa: [docs/README.md](docs/README.md) (frontend) e a documentação central em `RoosterOneBackend-main/docs/README.md`.

## Início rápido

```bash
npm install
npm run dev
```

Requer o backend rodando (`VITE_API_URL`, padrão `http://localhost:3000`).
